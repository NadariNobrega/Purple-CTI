# Purple CTI

Purple CTI is a Purple Team / CTI repository that documents owned infrastructure, operational observations, and security decisions. It serves as a record of architecture choices, telemetry sources, detection coverage, threat intelligence inputs, and changes to defensive posture.

This repository is maintained as a factual log of the environment and its evolution, including:

- Network and host infrastructure inventory relevant to security monitoring
- Data sources, collection boundaries, and retention policies
- Detection logic references and coverage mapping
- Observed simulated or unsolicited adversary activity, hypotheses, and investigative notes
- Security control decisions, exceptions, and risk tradeoffs

Content is written for internal technical audiences and assumes familiarity with operational security and CTI workflows.
